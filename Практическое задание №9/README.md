# Практическое занятие №9. Работа с файловым вводом-выводом

Клоков Иван Николаевич, ЭФБО-07-26

| Файл | Задача | Вход → выход |
|---|---|---|
| `zadacha1.cpp` | Удаление букв из "user agreement" | `input.txt` → `output.txt` |
| `zadacha2.cpp` | Является ли Y подстрокой X | `input1.txt`, `input2.txt` → yes/no |
| `zadacha3.cpp` | Числа в строке → двоичная запись | `input.txt` → `output.txt` |

В задаче 3 число может быть длиной до 255 цифр, поэтому перевод в двоичную
систему сделан делением строки на 2, без ограничения `long long`.

```
input.txt:  6^&678JKjdkdl;?.,lk879Pk1kdfl4839
output.txt: 110^&1010100110JKjdkdl;?.,lk1101101111Pk1kdfl1001011100111
```
