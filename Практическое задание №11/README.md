| Файл | Задача | Решение |
|---|---|---|
| `zadacha1.cpp` | Маршрут с максимумом баллов | `best[i][j] = a[i][j] + max(сверху, слева)`, путь восстанавливается с конца |
| `zadacha2.cpp` | Пирожки по дням | Сортировка, `dp[d][i] = min max(dp[d-1][j], a[i-1] - a[j])` |
| `zadacha3.cpp` | Букет из K растений, не больше L одинаковых | Ограниченный рюкзак по числу растений |

Пример к задаче 1:
```

2 -3 2 3
10 2 2 2
-3 20 2 2
Сумма баллов: 38
0 0
1 0
1 1
```
