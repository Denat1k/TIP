# Слияние двух отсортированных массивов (Scratch 3)

Лабораторная/практическая работа (ТИП).

## Задание

Есть два массива A и B, оба уже отсортированы по возрастанию. Нужно объединить
их в один массив, отсортированный по возрастанию, пройдя по обоим массивам
всего за один цикл вида:

```
Для Сч = 1 По a + b Цикл
```

## Как это сделано

Файл `merge_sorted_arrays.sb3` — готовый проект Scratch 3. В нём:

- список `A` и список `B` — исходные отсортированные массивы (заданы заранее);
- список `Result` — сюда пишется объединённый и отсортированный результат;
- переменные `a`, `b` — длины массивов, `i`, `j` — текущие указатели в A и B,
  `Сч` — счётчик итераций общего цикла;
- один спрайт со скриптом на алгоритм слияния: на каждом шаге сравнивается
  текущий элемент A и текущий элемент B, меньший забирается в `Result`,
  соответствующий указатель (`i` или `j`) сдвигается на 1; когда один из
  массивов заканчивается — забираются оставшиеся элементы второго;
- цикл выполняется ровно `a + b` раз, что соответствует условию задания;
- по ходу выполнения спрайт двигается, меняет цвет и размер, чтобы было видно
  каждый шаг слияния, а в конце — вспышка и сообщение "Готово!".

Проект можно открыть в Scratch 3 (scratch.mit.edu или офлайн-редактор) и
запустить зелёным флажком — на сцене видно оба исходных списка и результат
их слияния.

`scratch_merge.py` — Python-скрипт (только стандартная библиотека), которым
этот `.sb3`-файл сгенерирован. При запуске (`python3 scratch_merge.py`)
пересобирает `merge_sorted_arrays.sb3` заново.
