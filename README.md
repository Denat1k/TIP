# Слияние двух отсортированных массивов (Scratch 3)

Лабораторная/практическая работа (ТИП).

## Задание

Есть два массива A и B, оба уже упорядочены по возрастанию. Нужно за **один**
цикл вида

```
Для Сч = 1 По a + b Цикл
```

пройти по обоим массивам и выдать все значения по возрастанию — то есть
объединить массивы так, чтобы результат остался отсортированным.

## Как работает алгоритм

Держим два указателя: `i` — на текущий элемент A, `j` — на текущий элемент B.
На каждом шаге сравниваем `A[i]` и `B[j]`, забираем меньший в список `Result`
и сдвигаем только его указатель. Если один массив закончился — просто дозабираем
остатки второго. Шагов ровно `a + b`, сортировка не нужна: массивы и так
упорядочены.

## Что в файлах

- `merge_sorted_arrays.sb3` — сам проект, открывается в Scratch 3
  (scratch.mit.edu или офлайн-редактор), запуск по зелёному флажку.
- `scratch_merge.py` — скрипт на Python, которым проект собран.
  `python3 scratch_merge.py` пересобирает `.sb3` заново.

## Что видно на сцене

Элементы массивов показаны плитками с числами: бирюзовые — из A, оранжевые —
из B. Сверху над строками едут указатели `i` и `j`, сравниваемая пара
подсвечивается, выбранная плитка улетает вниз в строку результата. Справа
вверху счётчики `i`, `j` и `Сч`. В конце — салют и надпись «Готово!».
По цвету плиток в результате сразу видно, из какого массива пришло каждое
значение.

Массивы `A` и `B` можно поменять прямо в Scratch (вкладка «Переменные» →
списки). Главное — чтобы они оставались отсортированными по возрастанию;
на плитках рисуются числа от 1 до 25, сам алгоритм считает любые.
